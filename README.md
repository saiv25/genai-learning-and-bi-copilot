## Featured Project: AI Business Intelligence Copilot

An interactive sales analytics dashboard with an AI-powered
natural-language SQL assistant.

### Features
- Sales and profit KPI dashboard
- Interactive data filters
- Monthly sales and profit charts
- Natural-language SQL queries
- Excel-to-SQLite data pipeline
- CSV export

### Tech Stack
Python, Streamlit, Pandas, Plotly, SQLite,
LangChain, LangGraph, Groq

### Run the Application Locally

1. Install dependencies:
   pip install -r requirements.txt

2. Configure GROQ_API_KEY in your local .env file.

3. Import the sales data:
   python load_excel.py

4. Launch the app:
   streamlit run apps/4_sql_agent.py
